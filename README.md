# Week 3 – Data Cleaning and Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on cleaning and analysing the Titanic passenger dataset using Python.

## Objectives
- Handle missing values.
- Remove duplicate records.
- Detect and handle outliers.
- Encode categorical variables.
- Perform feature scaling.
- Analyse relationships between features.
- Create a correlation heatmap.
- Answer 10 analytical questions.

## Dataset
Titanic Passenger Dataset

- Original records: 891
- Cleaned records: 775
- Original columns: 15
- Cleaned columns: 14

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- VS Code

## Project Structure
- dataset – Original dataset
- cleaned_data – Cleaned and processed datasets
- visualizations – Generated charts
- Week_3_Data_Cleaning_EDA.ipynb – Complete analysis
- Week_3_Insights_Report.md – Project findings and insights

## Key Findings
- Overall survival rate: 41.29%.
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than other classes.
- Passenger class and fare showed a negative correlation.

## Conclusion
This project provided practical experience in data cleaning, preprocessing, exploratory data analysis, and data visualisation using Python.S
